# Изменения

## 1.2.1

- Флажок «Скачивать все без проверки дублей» включён по умолчанию; при наведении появляется понятная подсказка.
- Если снять флажок, одинаковое содержимое внутри одной папки определяется по SHA-256 Яндекса и сохраняется один раз. Файлы без суммы и копии в разных папках сохраняются отдельно.
- Защита от повторных загрузок работает независимо от флажка. При смене настройки пропущенные экземпляры догружаются.
- В выборе режима оставлены два пункта: оригиналы с заменой недоступных фото копиями и только оригиналы.
- Обновлены описание проблемы в README и инструкция для начинающих.

## 1.2.0

- Всплывающее окно 600 × 600; закрытие окна не останавливает задания.
- Независимые загрузки из нескольких вкладок без ограничения количества альбомов.
- Полный обход страниц и подпапок, сохранение пути от корневого каталога.
- Поддержка видео, документов и остальных файлов; копии для просмотра только для фото.
- Пауза, продолжение, стоп и повтор ошибок отдельно для каждого задания.
- Локальная история загрузок, проверка сохранённых оригиналов и обновление превью до оригинала.
- Новая иконка, подробная установка и автоматическая сборка ZIP в Releases.
