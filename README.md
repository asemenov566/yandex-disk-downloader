# Загрузчик Яндекс Диска

В октябре 2026 года пострадали дата-центры Яндекса — компания сообщила о повреждениях в Сасове и Калуге ([официальное сообщение](https://yandex.cloud/ru/blog/iron-hearts)). На фоне сбоев часть файлов Яндекс Диска недоступна. В проверенных папках не работает массовое скачивание архивом, а некоторые файлы не удаётся скачать даже по одному. У фотографий иногда остаётся доступное превью, хотя оригинал уже не скачивается: его можно сохранить, но с потерей качества.

**yandex-disk-downloader — временная полумера, чтобы сохранить доступную сейчас часть вашего архива.** Расширение скачивает фотографии, видео, документы и другие файлы по публичной ссылке, само проходит все вложенные папки и сохраняет их структуру на компьютере. Если оригинал фотографии недоступен, оно пробует сохранить копию для просмотра. Восстановить недоступные файлы расширение не может.

Можно вручную запускать скачивание по той же ссылке каждый день: уже сохранённые файлы будут учтены, а вновь доступные — догружены. Если вместо превью появился оригинал, расширение скачает его. Существующие файлы проверяются непосредственно в выбранной папке, даже после переустановки и с пустой историей. Старые preview остаются на месте.

**Берегите важные документы и фотографии: храните их резервные копии локально, а не только в облаке.**

## Как пользоваться

1. На Яндекс Диске выберите каталог, содержимое которого хотите скачать, и создайте для него ссылку через **«Поделиться» → «Скопировать ссылку»**.
2. Откройте полученную ссылку в Chrome.
3. Нажмите значок расширения — жёлтую папку со стрелкой, проверьте ссылку и нажмите **«Скачать всё»**.
4. При первом скачивании сразу откроется системное окно выбора папки. Выберите папку и разрешите доступ. Внутри выбранной папки создаётся **yandex-disk → название каталога**; существующая папка yandex-disk используется повторно.
5. Сменить папку можно через **шестерёнку → Папка скачивания → Изменить папку**. Нажатие этой кнопки останавливает все задания, даже если затем отменить выбор. Продолжить скачивание нужно вручную. Уже скачанные файлы не перемещаются. После смены папки кнопка «Продолжить» скачивает оставшуюся очередь; «Скачать всё» проверяет весь альбом в новом месте.

**Ссылка специально задаёт область действия расширения:** оно обрабатывает выбранный каталог и всё внутри него. Не обязательно создавать ссылку непосредственно на папку с файлами: можно поделиться общей папкой, например «Семейный архив», где внутри находятся годы, события и ещё несколько уровней папок. Расширение само обойдёт их все и сохранит структуру. Отдельные ссылки на каждую подпапку не нужны.

Для нескольких отдельных каталогов создайте ссылки, откройте их в разных вкладках и запустите расширение на каждой. Количество независимых заданий искусственно не ограничено. Список заданий и управление ими доступны в одном всплывающем окне.

Окно расширения размером 600 × 600 можно закрыть: очередь продолжит работать в фоне. Сам Chrome должен оставаться запущенным. После перезапуска браузера откройте расширение и нажмите «Продолжить».

В меню шестерёнки справа сверху есть **«Открыть окно»** — отдельное окно 600 × 600 без панели вкладок — и **«Открыть вкладку»** в текущем обычном окне Chrome. Они показывают ту же очередь и выбранное задание; новые скачивания не создаются.

Когда в списке больше одного задания, под блоком публичной ссылки появляется **«Общий прогресс»**. Он всегда открыт: общие счётчики, текущие файлы, кнопки для всех заданий и выбор задания находятся внутри. Это сумма всех заданий в списке, включая завершённые и приостановленные. Общий процент считается по числу файлов, а не как среднее процентов альбомов.

В отдельном окне и вкладке внутри общего блока доступен аккордеон **«Ошибки и пропуски всех заданий»**. В нём показаны все проблемные файлы и папки, полный путь от названия общего каталога и причина. В маленьком окне у значка расширения остаётся список ошибок выбранного задания.

## Что умеет

- Читает все страницы списка, включая альбомы с сотнями и тысячами файлов.
- Сам проходит вложенные папки.
- В каждом задании сначала скачивает фотографии из всех подпапок, затем вторым проходом видео, документы и остальные файлы. Этот порядок действует и при продолжении сохранённой очереди.
- Для ссылки на вложенную папку сохраняет название корневого альбома и весь путь до выбранной папки.
- Скачивает с общим лимитом от 1 до 50 файлов одновременно. Папка выбирается один раз, без запроса для каждого файла.
- Пробует все типы файлов: фото, видео, документы и другие. Пропускает пустые файлы и ошибки; отсутствие данных в течение выбранного времени (по умолчанию 25 секунд) тоже считается ошибкой.
- У каждого задания есть «Пауза», «Продолжить», «Стоп» и повтор ошибок.
- Сохраняет CSV-отчёт об оригиналах, копиях, пропусках и ошибках.

**Несколько заданий работают независимо, без лимита на число альбомов.** Общий лимит одновременно скачиваемых файлов задаётся в меню шестерёнки: 1 (по умолчанию), 5, 10 … 50. Он действует и внутри одного альбома. Увеличение применяется сразу; при уменьшении начатые файлы завершаются, а новые ждут свободного места. В этом же меню можно удалить задание, сохранив скачанные файлы и историю. Оригиналы и preview показаны отдельными счётчиками. Повторный запуск уже активной ссылки открывает существующее задание. Пересекающиеся деревья одного альбома обрабатываются последовательно, чтобы не скачивать одинаковые файлы одновременно.

«Пауза» сохраняет текущее задание для продолжения. «Стоп» завершает его без удаления скачанного; следующий запуск заново читает каталог и сверяется с файлами в выбранной папке.

При новом запуске расширение сначала проверяет файлы по ожидаемому имени и пути внутри выбранной папки / yandex-disk. Если оригинал существует и его размер совпадает с размером на Диске, запросы оригинала и preview не выполняются. Если есть только preview, автоматический режим пробует оригинал; при его недоступности используется существующая копия. Новый preview с номером не создаётся.

Проверка не зависит от базы расширения и истории скачиваний Chrome. При несовпадении размера существующий файл не перезаписывается: расширение показывает ошибку для ручной проверки. Контрольная сумма существующего файла заново не вычисляется; совпадение имени и размера не гарантирует одинаковое содержимое. Файлы в других папках и ранее созданные копии с добавленным номером не переименовываются и не удаляются.

### Одинаковые файлы и повторное скачивание

Флажок **«Скачивать все без проверки дублей» включён по умолчанию**. Если в одной папке Яндекс Диска лежат два одинаковых файла под разными именами, будут сохранены оба. Подсказка при наведении на флажок напоминает об этом.

Если снять флажок, расширение сравнит контрольные суммы SHA-256, полученные от Яндекса, и сохранит одну копию одинаковых файлов внутри каждой папки. В разных папках копии сохраняются отдельно. Если надёжной контрольной суммы нет, файл скачивается. Настройка применяется при нажатии «Скачать всё» и не удаляет уже скачанные дубли.

**Защита от повторного скачивания одного и того же уже сохранённого файла работает при любом положении флажка.** Если сначала скачали без дублей, а потом включили флажок и запустили каталог заново, расширение догрузит пропущенные экземпляры.

## Папки создаются автоматически

Например, ссылка на «Семейный альбом → 0 лет → Выписка → retouch» сохранится так:

```text
Выбранная папка/
└── yandex-disk/
    └── Семейный альбом/
        └── 0 лет/
            └── Выписка/
                └── retouch/
                    ├── DSC_0001.JPG
                    └── DSC_0002.preview.jpg
```

Путь берётся из публичной ссылки, название альбома — из данных Яндекс Диска. Открывать каждую папку вручную не нужно. При запуске из корня будут обработаны все подпапки; при запуске из вложенной папки — только она и её содержимое.

Используется папка, выбранная в расширении. Для прежних загрузок выбирайте родительскую папку существующей yandex-disk. Недопустимые символы в названиях заменяются. Файлы пишутся напрямую в выбранную папку и не появляются в списке скачиваний Chrome; прогресс виден в расширении. Существующие файлы не перезаписываются и копии с номером не создаются.

## Оригиналы и копии

| Режим | Что сохраняется |
| --- | --- |
| Оригиналы с заменой недоступных фото копиями | Сначала оригинал. При ошибке фото — копия для просмотра. После трёх последовательных ошибок оригиналов остальные фото загружаются копиями. При новом запуске для уже сохранённых превью оригинал проверяется снова. |
| Только оригиналы | Только исходные файлы. Недоступные оригиналы попадут в ошибки. |

Настройка копий относится только к фотографиям. Видео, документы и остальные файлы всегда скачиваются в оригинале.

Копии отмечены **`.preview`** в имени. Их разрешение, качество и метаданные могут отличаться от исходника. Расширение не восстанавливает недоступные оригиналы и не включает отключённое Яндексом скачивание ZIP.

Запрос списка или ссылки на файл ждёт до 20 секунд. Передача прерывается после выбранного времени **без поступления данных** (по умолчанию 25 секунд); это не ограничение общей длительности скачивания. Большое видео может скачиваться много минут, пока данные поступают. В окне видны этап ожидания и объём файла. «Пауза» и «Стоп» прерывают передачу; незавершённый файл при продолжении скачивается заново. При ответе 429 очередь приостанавливается — продолжите позже.

## Ограничения

Поддерживаются публичные ссылки вида `https://disk.yandex.ru/d/…`, `/i/…` и `yadi.sk`, включая вложенные пути. Личный раздел `/client/disk`, закрытые и защищённые паролем папки не поддерживаются.

Обычные изображения проверяются декодированием. Оригиналы фото дополнительно проверяются по размеру и SHA-256, когда он предоставлен Яндексом. Для RAW, TIFF и HEIC полноценное декодирование в Chrome не гарантируется — остаются проверки размера и контрольной суммы. Максимум 512 МБ на фотографию, обрабатываемую в памяти.

Видео, документы и другие файлы записываются потоком непосредственно в выбранную папку, без загрузки всего файла в память. Перед завершением записи проверяется размер, известный Яндексу. При ошибке или отмене незавершённая запись отбрасывается. Ранее существующие файлы не удаляются.

Во время сканирования желательно не менять содержимое альбома: перемещение файлов может сдвинуть страницы списка. Очень длинные пути могут не сохраниться из-за ограничений операционной системы.

## Доступ и личные данные

Расширение не требует пароль Яндекса, не читает cookies и не отправляет фотографии сторонним сервисам. Оно обращается к API и файловым серверам Яндекса по указанной публичной ссылке. Задания, история загрузок, пути файлов и результаты хранятся локально в браузере.

Разрешения:

| Разрешение | Для чего |
| --- | --- |
| Загрузки | Восстанавливать состояние незавершённых загрузок старых версий |
| Доступ к выбранной папке | Проверять существующие файлы и сохранять новые внутри yandex-disk; запрашивается при выборе папки |
| power и alarms | Предотвращать автоматический сон при активной очереди и проверять фоновый обработчик |
| Активная вкладка | Подставлять публичную ссылку при нажатии значка расширения |
| Фоновый документ | Проверять изображения и продолжать очередь после закрытия всплывающего окна |
| Серверы Яндекса | Получать список файлов, оригиналы и копии |

[Подробнее о данных](PRIVACY.md).

## Разработка и сборка

Само расширение работает без установки библиотек и без сборки. Его файлы находятся в `extension/`.

Для тестов нужен Node.js 22 или новее:

```sh
npm test
```

Для ZIP нужен Python 3:

```sh
python scripts/build.py
```

Архив появится в `dist/yandex-disk-downloader.zip`. Папка `dist` и ZIP исключены из Git. В GitHub Actions проверка запускается для ветки `main` и pull request. При отправке новой версии в `main` либо ручном запуске Release создаётся релиз с архивом. Уже выпущенная версия автоматически не перезаписывается. **ZIP публикуется только в Releases, не в исходниках.**

Проверки охватывают пагинацию более 500 файлов, вложенные пути, обход подпапок, независимость очереди от окна, паузу/продолжение, восстановление сохранения, повреждённые изображения, размер/хеш и ограничения API. [Статус проверок](docs/verification.md).


## Общее управление и сохранённая папка (1.3.3)

В общем прогрессе при нескольких заданиях появляются «Продолжить все» для остановленных и приостановленных незавершённых заданий и «Остановить все» для работающих и ожидающих запуска. Если есть оба вида заданий, доступны обе кнопки. Общая остановка сохраняет прогресс; продолжение обрабатывает оставшуюся очередь, не обходит весь архив заново и не запускает завершённые задания. Незавершённый текущий файл скачивается заново. Повтор ошибок, ожидавший запуска, сохраняет свой режим, включая выбранный повтор preview.

При первом скачивании открывается только системный диалог выбора папки. При обновлении или повторном открытии окна расширения папка загружается из сохранённых данных. Если разрешение ещё действует, подтверждать её не нужно. Если Chrome потребует разрешение снова, расширение запрашивает доступ к уже сохранённой папке. В предложении Chrome выбирайте «Разрешать при каждом посещении», если такой вариант доступен; отменённое или отозванное разрешение расширение не может восстановить без вашего участия. [Описание постоянных разрешений Chrome](https://developer.chrome.com/blog/persistent-permissions-for-the-file-system-access-api).


## Общие действия и настройки (1.3.4)

В общем прогрессе для завершённых заданий доступна кнопка «Повторить всё»: повторно прочитать каталоги и скачать недостающее с проверкой существующих файлов. «Повторить все ошибки» использует сохранённые списки завершённых заданий; общий флажок «Считать preview ошибкой» добавляет попытки получить оригиналы вместо копий. Остановленные и работающие задания этими кнопками не перезапускаются.

Количество одновременных скачиваний и ожидание данных расположены в настройках рядом, по половине строки. Ожидание: 5, 15, 25, 40, 60, 120 или 240 секунд; по умолчанию 25. Выбор сохраняется и действует для следующих файлов. Лимит одновременных скачиваний меняется сразу.


## Расположение блоков (1.3.5)

Блок публичной ссылки расположен первым под шапкой. При нескольких заданиях общий прогресс всегда открыт; в нём находятся общие кнопки и список «Задания · независимые загрузки». При одном задании общий блок и список скрыты.

Карточка «Загрузка — название страницы» при нескольких заданиях по умолчанию свёрнута, её можно раскрыть нажатием на заголовок. При одном задании она всегда открыта и не сворачивается. Отдельный крупный заголовок альбома убран.


## Блок ссылки (1.3.6)

Блок публичной ссылки сворачивается. Без заданий он открыт по умолчанию, при наличии хотя бы одного — свёрнут. Ручное раскрытие или сворачивание сохраняется при обновлении прогресса; после удаления всех заданий блок снова открывается.


## Переносимая база (1.3.7)

Задания, прогресс, ошибки, preview, история сохранённых файлов и настройки теперь сохраняются в yandex-disk/downloader-state.json. После переустановки выберите прежнюю родительскую папку: задания восстановятся без автоматического запуска. В JSON отдельно указаны версия расширения и версия формата. Перед преобразованием старой структуры создаётся резервная копия; повреждённый или неизвестный новый формат не перезаписывается.

Обновите установленное расширение в его прежней папке и один раз откройте его с доступом к папке скачивания: существующая база Chrome будет перенесена в JSON, если файла ещё нет. Перед удалением старой установки убедитесь, что downloader-state.json появился. Уже удалённую до этого базу Chrome восстановить из файлов фотографий нельзя.

При выборе другой папки существующая JSON-база этой папки заменяет список заданий в интерфейсе. Если JSON нет, в новую папку переносится текущий список остановленных заданий. Фотографии не перемещаются. Папку скачивания и JSON можно скопировать на другой компьютер и выбрать там её родительскую папку. Браузер всё равно должен разрешить доступ к этой папке.

Сохраняется текущая очередь и история файлов, а не бесконечный журнал каждого нажатия. Запись JSON фиксируется после контрольных точек очереди, изменения настроек и удаления задания. При аварийном завершении восстанавливается последняя полностью сохранённая точка; наличие файлов проверяется отдельно.


## Общие кнопки (1.3.8)

Общий блок использует те же размеры и оформление кнопок, что и отдельная загрузка: «Продолжить все», «Приостановить все», «Остановить все», «Повторить все ошибки» с флажком preview и «Отчёт по всем». Недоступные действия остаются видны, но неактивны. Отдельная кнопка «Повторить всё» заново проверяет завершённые альбомы; существующие файлы не дублируются.

Общая пауза сохраняет место и ожидавший повтор ошибок. «Отчёт по всем» доступен после паузы или завершения всех заданий и сохраняет один CSV в yandex-disk с названием альбома и публичной ссылкой для каждой строки.


## Новые файлы за запуск (1.3.9)

В карточке выбранной загрузки вместо режима качества показан процент обработки её файлов. Рядом зелёная метка «Новых: N» считает только реально сохранённые оригиналы и preview за текущий запуск, включая получение оригинала вместо preview. Уже существующие файлы, пропуски и неудачные загрузки не увеличивают счётчик. Новый обход или повтор ошибок сбрасывает его; пауза, продолжение и повторное открытие интерфейса сохраняют.

Процент считается так же, как общий: обработанные файлы, включая ошибки и пропуски, делятся на количество найденных файлов выбранного задания. Поэтому 100% означает завершение обработки, а не отсутствие ошибок. Метка «Новых» показывает только новые записи на диск в этом запуске.


Зелёная метка «Новых» у общего прогресса считает новые записи после последнего общего повтора. «Повторить всё» и «Повторить все ошибки» начинают отсчёт с нуля: старые результаты других заданий не добавляются. Уже работающие задания продолжаются; в общий счётчик попадают только их последующие сохранения. Их отдельные счётчики сохраняют результат всего своего запуска. Пауза, продолжение и восстановление JSON-базы сохраняют оба счётчика. Повтор отдельного задания обнуляет только его счётчик и вклад в общий результат.
