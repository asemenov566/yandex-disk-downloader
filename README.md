# Загрузчик Яндекс Диска

Когда Яндекс Диск отключает «Скачать всё» или скачивание папки архивом, большой фотоальбом приходится сохранять вручную — по одной фотографии. **yandex-disk-downloader** скачивает фотографии, видео и другие файлы по публичной ссылке, проходит все страницы списка и вложенные папки и сохраняет их на компьютер с той же структурой. Если оригинал недоступен, расширение может сохранить доступную копию для просмотра.

GitHub не может установить его автоматически; [Chrome поддерживает прямую пользовательскую установку через свой магазин](https://developer.chrome.com/docs/extensions/how-to/distribute).

## Как пользоваться

1. На Яндекс Диске выберите каталог, содержимое которого хотите скачать, и создайте для него ссылку через **«Поделиться» → «Скопировать ссылку»**.
2. Откройте полученную ссылку в Chrome.
3. Нажмите значок расширения — жёлтую папку со стрелкой, проверьте ссылку и нажмите **«Скачать всё»**.
4. Файлы появятся в **Загрузки → yandex-disk → название каталога**.

**Ссылка специально задаёт область действия расширения:** оно обрабатывает выбранный каталог и всё внутри него. Не обязательно создавать ссылку непосредственно на папку с файлами: можно поделиться общей папкой, например «Семейный архив», где внутри находятся годы, события и ещё несколько уровней папок. Расширение само обойдёт их все и сохранит структуру. Отдельные ссылки на каждую подпапку не нужны.

Для нескольких отдельных каталогов создайте ссылки, откройте их в разных вкладках и запустите расширение на каждой. Количество независимых заданий искусственно не ограничено. Список заданий и управление ими доступны в одном всплывающем окне.

Окно расширения размером 600 × 600 можно закрыть: очередь продолжит работать в фоне. Сам Chrome должен оставаться запущенным. После перезапуска браузера откройте расширение и нажмите «Продолжить».

## Что умеет

- Читает все страницы списка, включая альбомы с сотнями и тысячами файлов.
- Сам проходит вложенные папки.
- Для ссылки на вложенную папку сохраняет название корневого альбома и весь путь до выбранной папки.
- Скачивает файлы по одному в каждом задании; разные задания работают одновременно. Не запрашивает место сохранения для каждого файла.
- Пробует все типы файлов: фото, видео, документы и другие. Пропускает пустые файлы и ошибки; отсутствие данных 25 секунд тоже считается ошибкой.
- У каждого задания есть «Пауза», «Продолжить», «Стоп» и повтор ошибок.
- Сохраняет CSV-отчёт об оригиналах, копиях, пропусках и ошибках.

**Несколько заданий работают независимо, без лимита на число альбомов.** Повторный запуск уже активной ссылки открывает существующее задание. Пересекающиеся деревья одного альбома обрабатываются последовательно, чтобы не скачивать одинаковые файлы одновременно.

«Пауза» сохраняет текущее задание для продолжения. «Стоп» завершает его без удаления скачанного; следующий запуск заново читает каталог и сверяется с историей.

При новом запуске сохранённый оригинал проверяется по записи Chrome: файл существует, сохранение завершено, путь и размер совпадают, данные исходника не изменились. Такой файл повторно не скачивается. Если сохранилось только превью, автоматический режим снова пробует оригинал. После успешного сохранения оригинала и проверки его размера расширение удаляет своё старое превью. При ошибке оригинала превью остаётся.

История относится только к загрузкам этого расширения. Оно не сканирует произвольные файлы на диске и не вычисляет их хеш повторно. Если файл перемещён или история Chrome очищена, возможна повторная загрузка. Совпадение размера не обнаруживает изменение содержимого при сохранённой длине.

## Папки создаются автоматически

Например, ссылка на «Семейный альбом → 0 лет → Выписка → retouch» сохранится так:

```text
Загрузки/
└── yandex-disk/
    └── Семейный альбом/
        └── 0 лет/
            └── Выписка/
                └── retouch/
                    ├── DSC_0001.JPG
                    └── DSC_0002.preview.jpg
```

Путь берётся из публичной ссылки, название альбома — из данных Яндекс Диска. Открывать каждую папку вручную не нужно. При запуске из корня будут обработаны все подпапки; при запуске из вложенной папки — только она и её содержимое.

Используется папка загрузок, настроенная в Chrome: она может отличаться от стандартной «Загрузки». Недопустимые символы в названиях заменяются. Существующие файлы не перезаписываются: для нераспознанных совпадений Chrome добавляет номер.

## Оригиналы и копии

| Режим | Что сохраняется |
| --- | --- |
| Оригинал → копия | Сначала оригинал. При ошибке — копия для просмотра. После трёх последовательных ошибок оригиналов остальные фото загружаются копиями. |
| Только оригиналы | Только исходные файлы. Недоступные оригиналы попадут в ошибки. |
| Копии для просмотра | Доступные изображения для просмотра. В проверенных альбомах — до 1280 пикселей по большей стороне. |

Настройка копий относится только к фотографиям. Видео, документы и остальные файлы всегда скачиваются в оригинале.

Копии отмечены **`.preview`** в имени. Их разрешение, качество и метаданные могут отличаться от исходника. Расширение не восстанавливает недоступные оригиналы и не включает отключённое Яндексом скачивание ZIP.

Запрос списка или ссылки на файл ждёт до 20 секунд. Передача фото прерывается после 25 секунд **без поступления данных**; это не ограничение общей длительности скачивания. При ответе 429 очередь приостанавливается — продолжите позже.

## Ограничения

Поддерживаются публичные ссылки вида `https://disk.yandex.ru/d/…`, `/i/…` и `yadi.sk`, включая вложенные пути. Личный раздел `/client/disk`, закрытые и защищённые паролем папки не поддерживаются.

Обычные изображения проверяются декодированием. Оригиналы фото дополнительно проверяются по размеру и SHA-256, когда он предоставлен Яндексом. Для RAW, TIFF и HEIC полноценное декодирование в Chrome не гарантируется — остаются проверки размера и контрольной суммы. Максимум 512 МБ на фотографию, обрабатываемую в памяти.

Видео, документы и другие файлы передаются штатному загрузчику Chrome, без этого ограничения памяти. Проверяются завершение сохранения и размер, известный Яндексу; повторное чтение и проверка хеша файла на диске недоступны. Файлы с несовпавшим размером удаляются, если Chrome разрешает удалить загрузку этого расширения.

Во время сканирования желательно не менять содержимое альбома: перемещение файлов может сдвинуть страницы списка. Очень длинные пути могут не сохраниться из-за ограничений операционной системы.

## Доступ и личные данные

Расширение не требует пароль Яндекса, не читает cookies и не отправляет фотографии сторонним сервисам. Оно обращается к API и файловым серверам Яндекса по указанной публичной ссылке. Задания, история загрузок, пути файлов и результаты хранятся локально в браузере.

Разрешения:

| Разрешение | Для чего |
| --- | --- |
| Загрузки | Сохранять файлы, проверять завершение, отменять собственные загрузки и удалять своё превью после сохранения оригинала |
| Активная вкладка | Подставлять публичную ссылку при нажатии значка расширения |
| Фоновый документ | Проверять изображения и продолжать очередь после закрытия всплывающего окна |
| Серверы Яндекса | Получать список файлов, оригиналы и копии |

[Подробнее о данных](PRIVACY.md).

## Разработка и сборка

Само расширение работает без установки библиотек и без сборки. Его файлы находятся в `extension/`.

Для тестов нужен Node.js 22 или новее:

```sh
npm test
```

Для ZIP нужен Python 3:

```sh
python scripts/build.py
```

Архив появится в `dist/yandex-disk-downloader.zip`. Папка `dist` и ZIP исключены из Git. В GitHub Actions проверка запускается для ветки `main` и pull request. При отправке новой версии в `main` либо ручном запуске Release создаётся релиз с архивом. Уже выпущенная версия автоматически не перезаписывается. **ZIP публикуется только в Releases, не в исходниках.**

Проверки охватывают пагинацию более 500 файлов, вложенные пути, обход подпапок, независимость очереди от окна, паузу/продолжение, восстановление сохранения, повреждённые изображения, размер/хеш и ограничения API. [Статус проверок](docs/verification.md).
