# Проверки версии 1.2.3

Автоматические тесты запускаются командой npm test на Node.js 22+. Они проверяют пагинацию более 500 файлов, сокращённые сервером страницы, иерархию, обход папок, параллельные задания, защиту от пересекающихся загрузок, отсутствие лимита количества альбомов, паузу и стоп, продолжение после перезапуска, пропуск пустых файлов, HTTP-ошибки, 429, проверку изображений, размера и SHA-256, тайм-аут прямой загрузки, сохранение видео и документов, повторное использование оригинала и замену превью.

Отдельно проверено: при недоступном оригинале превью сохраняется; при несовпадении размера оригинала превью не удаляется; отсутствующий или изменившийся файл загружается заново.

Для проверки одинакового содержимого протестированы оба положения флажка: сохранение всех отдельных исходных файлов по умолчанию, объединение по SHA-256 только внутри одной папки, разные даты одинаковых файлов, отсутствие суммы, удалённая локальная копия, обновление общего превью и смена настройки после перезапуска без повторной загрузки уже сохранённого.

Всего проходит 51 автоматический тест. Проверены зависший ответ Chrome о запуске загрузки, поздний возврат её номера, зависшие ответы о состоянии и отмене, пауза и стоп до получения номера, остановка задания, ожидающего проверку дублей. Проверены фотографии перед видео во всех подпапках после восстановления очереди и десятиминутная передача видео, которая не прерывается, пока поступают данные.

В версии 1.2.3 добавлены проверки общего процента по количеству файлов, учёта завершённых и приостановленных заданий, видимости только при двух и более работающих ссылках, полного списка ошибок и путей из вложенного публичного каталога.

Интерфейс также проверен в отдельном тестовом Chrome на синтетических данных с подменой API расширения: раскрытие обоих аккордеонов, сохранение раскрытого состояния при обновлении прогресса, полные пути ошибок, отсутствие общего списка ошибок в маленьком окне, параметры открытия окна 600 × 600 и вкладки в исходном окне, отсутствие запуска новой очереди этими кнопками. Сделаны и просмотрены снимки интерфейса 600 × 600; ошибок страницы не обнаружено. Проверка не затрагивала текущие пользовательские скачивания.

В живой проверке публичного фотоальбома получено 40 копий для просмотра; ещё пять фото вернули HTTP 500/503. Все 40 сохранённых изображений прошли дополнительную проверку декодирования. Личные ссылки и фотографии в репозиторий не включены.

Тесты очереди используют подмену API Chrome. Пользователь подтвердил реальные скачивания видео предыдущей версии снимком сохранённых файлов. Полная проверка установленной версии 1.2.3 в пользовательском Chrome пока не завершена. Сообщение о восьмиминутной задержке помогло обнаружить неограниченное ожидание ответа Chrome в коде; точное место задержки на компьютере пользователя инструментально не подтверждено. Работа фонового документа после закрытия вкладки и удаление превью через Chrome также требуют проверки в установленном расширении. Эти проверки не выдаются за выполненные.
