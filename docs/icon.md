# Иконка

Иконка создана встроенным генератором изображений 13 октября 2026 года для этого проекта. Это самостоятельная композиция, без официального логотипа Яндекса. Прозрачный фон; PNG в размерах 16, 32, 48, 128 и 256 пикселей находится в extension/icons. После генерации выполнено только уменьшение для размеров Chrome.

Исходный запрос:

> Use case: logo-brand. Asset type: square Chrome extension icon for yandex-disk-downloader, an independent photo album downloader. Create one polished simple raster icon: a warm yellow rounded folder, a small white photo card peeking from inside (blue mountain silhouette), and a bold deep-blue downward arrow centered on the folder. Flat crisp shapes, very restrained soft depth, strong recognizable silhouette at 16 and 32 pixels, balanced generous margins, centered composition. No text, no letters, no official Yandex logo, no watermark, no border or surrounding scene. Transparent canvas outside the icon. Square format.
