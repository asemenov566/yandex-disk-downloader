## Новое в версии 1.2.4

Рядом с «Повторить ошибки» добавлен чекбокс **«Считать preview ошибкой»**.

- Без галочки повторяются только ошибки файлов и папок.
- С галочкой также повторяется попытка скачать оригиналы для preview из истории выбранного задания, даже если обычных ошибок нет.
- Флажок действует только при нажатии «Повторить ошибки» и не меняет первое скачивание.
- Уже прочитанные папки не обходятся заново, готовые оригиналы повторно не скачиваются.
- Если оригинал пока недоступен, сохранённое preview остаётся. Оно удаляется только после успешного сохранения и проверки оригинала.

## Обновление с сохранением заданий и ошибок

1. Поставьте загрузки на паузу.
2. Скачайте **yandex-disk-downloader.zip** из вложений релиза и распакуйте архив.
3. Замените файлы в **той же папке extension**, из которой установлено расширение.
4. На странице `chrome://extensions` нажмите круглую стрелку обновления на карточке расширения.
5. Выберите старое задание, включите «Считать preview ошибкой» и нажмите «Повторить ошибки».

**Не удаляйте расширение перед обновлением:** при удалении Chrome стирает сохранённую очередь. Формат базы IndexedDB не изменён; при обновлении существующей установки задания, ошибки и история сохраняются. Сохраните также историю загрузок Chrome и сами скачанные файлы: они нужны для проверки существующих оригиналов и preview. Экспорт и импорт базы в этой версии не добавлены.

## Первая установка

Скачайте ZIP, распакуйте его и выберите папку **extension** в Chrome → `chrome://extensions` → «Загрузить распакованное расширение» в режиме разработчика. Подробная инструкция — в install.md внутри архива.
