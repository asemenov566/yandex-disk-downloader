Скачайте **yandex-disk-downloader.zip**, распакуйте его и выберите папку **extension** в Chrome → chrome://extensions → «Загрузить распакованное расширение».

Пошаговая инструкция для начинающих находится в install.md внутри архива и в репозитории.

Создайте публичную ссылку на нужный каталог Яндекс Диска, откройте её в Chrome и нажмите значок расширения → «Скачать всё». Можно дать ссылку на общую папку: все подпапки будут обработаны автоматически. Ссылка определяет область скачивания.

Новое в версии 1.2.2:

- Сначала фотографии из всех подпапок задания, затем вторым проходом видео, документы и остальные файлы. Порядок применяется и к сохранённым очередям.
- Исправлено неограниченное ожидание запуска загрузки в Chrome: теперь оно ограничено 25 секундами. Большие видео могут скачиваться дольше, пока поступают данные.
- «Пауза» и «Стоп» прерывают ожидание запуска и ожидание другого задания при проверке одинаковых файлов. Поздно запустившаяся отменённая загрузка получает команду отмены.
- В окне показаны текущий проход, этап ожидания и скачанный объём.
- Прошли 47 автоматических тестов, включая зависшие ответы Chrome, поздний запуск, остановку и продолжение очереди.

Перед обновлением поставьте задания на паузу. Если старая версия зависла и не реагирует, отмените её зависшие загрузки в списке Chrome (Ctrl+J). Замените файлы в установленной папке extension и нажмите круглую стрелку на карточке расширения в chrome://extensions. После обновления выберите задание и нажмите «Продолжить». Удалять расширение не нужно.

Возможности расширения:

- Всплывающее окно 600 × 600 и фоновая очередь.
- Независимые задания из разных вкладок без лимита количества альбомов.
- Фотографии, видео и остальные типы файлов, обход всех страниц и подпапок.
- «Пауза», «Продолжить», «Стоп», повтор ошибок и отчёт для каждого задания.
- Проверка истории сохранений и обновление превью до оригинала. Старое превью удаляется только после успешного сохранения оригинала.
- Автоматическое размещение в «Загрузки / yandex-disk / название каталога» с сохранением иерархии.

Уменьшенные фото отмечены .preview. Доступность оригиналов зависит от Яндекса. Полный Chrome должен оставаться запущенным; вкладку Диска и маленькое окно расширения можно закрыть.

Код очереди и сетевых проверок покрыт автоматическими тестами. Проверка всей версии в установленном пользовательском Chrome пока не завершена; подробности и ограничения — в docs/verification.md.
