При первом скачивании выберите папку. Для Яндекса создадим yandex-disk, для ВК — vk-messager.

Если на Яндекс Диске есть два одинаковых файла, при установленном флажке будут скачаны оба. Снимите флажок, чтобы сохранять одну копию одинаковых файлов внутри каждой папки. Уже скачанный файл повторно не загружается в любом случае.
Качество и структура папок

Режим можно менять во время загрузки: текущие передачи задания остановятся, подходящие файлы автоматически продолжатся. После завершения выберите нужный режим и нажмите «Продолжить» или «Продолжить все».

Сначала скачиваем фотографии из всех подпапок, затем видео, документы и остальные файлы. Видео и документы скачиваются в оригинале. При новом запуске проверяем сохранённое и пробуем заменить превью оригиналом.

ВК: откройте диалог и войдите в аккаунт, ссылку подставим автоматически. Вставленная ссылка откроет диалог. Собираем и сохраняем список вложений порциями по 30 с настраиваемой паузой, независимо от скачивания. Найденные фото и видео сразу поступают в очередь и скачиваются параллельно в vk-messager / название диалога. Сохранённые ссылки обновляем, если они стали недоступны. Видео: только MP4 с серверов ВК, если название содержит «Видео от», независимо от имени автора. Внешние хостинги и другие названия пропускаются. Вкладку диалога оставьте открытой. При засыпании вкладки или истечении токена автоматически обновим её и повторим запрос с сохранённой позиции. Если потребуется заново войти в аккаунт, покажем сообщение.

        Пропуски и ошибки
          Попап можно закрыть. Для ВК оставьте вкладку диалога открытой.

          Настройки

          Каждое задание получает свой лимит. ВК: фото + видео; «1» — один файл всего. В режиме одного типа используется только его часть лимита. Лимиты меняются сразу; время ожидания — для следующих файлов.

          Применяется со следующей порции. Ожидание общей очереди запросов ВК может увеличить интервал.

          Даты файлов

          Новые фотографии получают недостающие даты съёмки и создания внутри файла. Существующие даты сохраняются. Если их нет, используется дата загрузки, для ВК — дата сообщения при отсутствии даты загрузки. Даты фото и видео сохраняются в общий JSON и отдельно по папкам. Системная дата создания Windows не меняется.

          Диагностика

          Журнал log--дд-мм-гггг.log рядом с downloader-state.json в папке yandex-disk. Записывается каждые 5 секунд, для каждого дня — отдельный файл. В базе браузера журнал не хранится. Токены, ссылки на файлы и содержимое переписки не записываются.
